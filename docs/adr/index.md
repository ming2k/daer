# Architectural Decision Records

This directory records high-impact, non-reversible architectural and structural decisions made across the `daer` project.

| ID | Title | Status | Scope | Decision Summary & Primary Invariant | Date |
| :--- | :--- | :--- | :--- | :--- | :--- |
| [0001](0001-config-format.md) | The configuration format is TOML | Accepted | config/schema, config/parser | Abandon custom ANTLR DSL; adopt strictly-typed TOML with `deny_unknown_fields` and compile-time schema generation. | 2026-01-07 |
| [0002](0002-netune-boundary.md) | Network capabilities live in netune; the data path lives here | Accepted (Amended by ADR-0010, ADR-0017) | architecture/boundary, outbound/transport | Keep generic network capabilities in `netune`; proxy appliance data path, eBPF maps, transparent accept stay in `daer`, proxy protocols in `daer-proxy-protocols` [[INV-NETUNE-01]](../dev/standards/invariants.md). | 2026-01-07 |
| [0003](0003-datapath-abi.md) | The datapath object is an external artifact with its own ABI | **Superseded by ADR-0020** | ebpf/abi, kernel/c, datapath | Treat C eBPF datapath as an external artifact compiled via clang; access maps and programs via stable Aya ABI without linking C. | 2026-01-07 |
| [0004](0004-routing-epochs.md) | Routing epochs: two slots, publish then switch | Accepted | ebpf/maps, routing/hot-reload, kernel/sync | Dual-slot kernel routing epochs (`active_slot` toggle); fully publish new generation before switching [[INV-EPOCH-01]](../dev/standards/invariants.md). | 2026-01-07 |
| [0005](0005-kernel-policy-encoding.md) | The kernel policy table is written, and it is either provably equivalent to userspace or it defers | Accepted | datapath/policy, routing/lowering, control-plane | Lowers routing rules to kernel eBPF tables when provably equivalent; explicitly defers to userspace with logged reasons when predicates require userspace tables [[INV-KERNEL-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0006](0006-wiring-ownership.md) | A running daemon owns its whole data path: adapters that are not wired are deleted, not documented | Accepted | control-plane, outbound/selection, config, cli | Unify configuration loader across CLI diagnostics and running daemon (SSOT); delete unwired keys and enforce with automated script [[INV-LOADER-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0007](0007-verification.md) | A test that cannot fail is a liability: every claim about the data path names its falsifier | Accepted | verification, ci, documentation | Every datapath claim must name its falsifier and carry negative controls; reject tests that cannot fail [[INV-VERIFY-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0010](0010-reality-client-ownership.md) | REALITY and the minimal TLS 1.3 client belong to daer-outbound | Accepted (Amended by ADR-0017) | tls/reality, protocol/vless, security/egress | Implement unauthenticated TLS 1.3 client and REALITY directly in `daer` because netune cannot perform dials without CA validation (migrated to `daer-proxy-protocols` by ADR-0017). | 2026-10-29 |
| [0011](0011-partitioned-kernel-routing.md) | Partitioned kernel routing and DNS snooping for Real-IP datapaths | Accepted | datapath/policy, routing/lowering, control-plane, dns | Compile deterministic L4/IP prefix rules directly to kernel eBPF; gate unencodable rules at the partition boundary and accelerate Real-IP via DNS snooping [[INV-PARTITION-01]](../dev/standards/invariants.md). | 2026-01-08 |
| [0012](0012-optional-fake-ip-ebpf.md) | Pluggable Fake-IP subsystem and eBPF domain-bitmap synthesis | Accepted | dns/fake-ip, datapath/ebpf, control-plane/routing, config/schema | Isolate Fake-IP behind an optional disabled-by-default table; synthesize eBPF `domain_routing_map` entries for line-rate kernel domain routing [[INV-FAKEIP-01]](../dev/standards/invariants.md). | 2026-01-08 |
| [0013](0013-datapath-state-ownership.md) | The datapath owns its box-global state, and the kernel's observed facts reach userspace | Accepted (Amended by ADR-0038) | datapath/ebpf, datapath/attach, control-plane/routing, datapath/udp | Attaching the datapath owns the policy routing, sysctls, link-layer variant choice, and the UDP listener slot; `routing_handoff_map` supplies `mac`/`dscp`/`pname` to the router through `KernelObserver` [[INV-DATAPATH-01]](../dev/standards/invariants.md). Policy routing now lives in the private ingress namespace (ADR-0038). | 2026-02-14 |
| [0014](0014-drb-rule-binary-and-providers.md) | DRB (daer Rule Binary) compiled artifacts and declarative Rule Providers | Accepted | routing/drb, config/rule-providers, cli/rules, control-plane/loader | Precompiled zero-parsing DRB binary rule sets; declarative HTTP/file rule providers with a system-wide cache (`DAER_RULE_CACHE_DIR` override) and CLI compilation tooling [[INV-DRB-01]](../dev/standards/invariants.md), [[INV-PROVIDER-01]](../dev/standards/invariants.md). | 2026-02-15 |
| [0015](0015-cli-is-four-verbs.md) | The CLI is four verbs: producers are not shipped inside the runtime | Accepted | cli/surface, architecture/boundary, routing/drb, dns | Reduce the surface to `run`/`check`/`explain`/`schema`; move the DRB and URI producers to `daer-drb` and third-party tooling, delete `dns serve`, collapse duplicate diagnostics into one exit-status gate [[INV-CLI-01]](../dev/standards/invariants.md). | 2026-02-15 |
| [0016](0016-cli-route-and-probe.md) | CLI route and probe: natural networking mental model and tiered active diagnostics | Accepted | cli/surface, architecture/diagnostics, routing, outbound/probe | Replace `explain` with `route <TARGET>` for natural routing lookup; introduce tiered active online diagnostics via `probe node` and `probe url` [[INV-CLI-01]](../dev/standards/invariants.md). | 2026-02-16 |
| [0017](0017-proxy-protocols-crate-boundary.md) | Proxy protocols and crypto engines belong to daer-proxy-protocols | Accepted | architecture/boundary, outbound/protocols, crypto, crate-topology | Decouple proxy protocols and crypto engines from `daer-outbound` into `daer-proxy-protocols`; restore `daer-outbound` to a thin outbound governance layer. | 2026-10-31 |
| [0018](0018-userspace-data-path-is-daer-relay.md) | The userspace data path is a crate of its own, called daer-relay | Accepted | architecture/boundary, data-path, relay, crate-topology | Split transparent ingress, splice, UDP session table and flow supervision out of `daer-control` into `daer-relay`; `daer-control` decides and no longer carries. | 2026-10-31 |
| [0019](0019-rule-asset-topology-and-lookup-mechanics.md) | Rule asset topology: coarse-grained provider envelopes over monolithic archives and fragmented rule sets | Accepted | routing/lookup, config/rule-providers, architecture/data-path, ebpf/kernel-policy | Coarse-grained rule providers over fragmented rules; 1024-set kernel bound preservation; reject monolithic multi-tag archives; unified DRB container for orthogonal IP/domain pipelines [[INV-LOOKUP-01]](../dev/standards/invariants.md), [[INV-KERNEL-BOUND-01]](../dev/standards/invariants.md). | 2026-10-31 |
| [0020](0020-datapath-is-daer-own.md) | The datapath source is daer's own | Accepted | ebpf/kernel-c, ebpf/loader, datapath | The C datapath is daer's source, not a foreign artifact: sections are spelled the way `aya` parses natively, the `dae` vocabulary is erased, and the load-time ELF/BTF rewriter is deleted. Loader loads, it does not repair [[INV-DATAPATH-ABI-01]](../dev/standards/invariants.md). | 2026-11-06 |
| [0021](0021-kernel-abi-single-source.md) | The kernel ABI has exactly one source | Accepted | ebpf/abi, kernel/c, build/xtask | `ebpf/abi.toml` is the single source for map/program names, discriminants and struct layouts; `cargo xtask abi` generates both `daer_abi.h` and `generated.rs`; CI fails on drift [[INV-ABI-01]](../dev/standards/invariants.md). | 2026-11-06 |
| [0022](0022-datapath-tests-are-rust.md) | In-kernel datapath tests are Rust, and they run in CI | Accepted | verification, ebpf/tests, ci | Port the Go `BPF_PROG_TEST_RUN` harness to `crates/daer-ebpf/tests/datapath.rs`, keep the C test programs, discover cases from the object, and make the suite part of `cargo xtask ci`. | 2026-11-06 |
| [0023](0023-constants-have-one-definition.md) | Constants have one definition and no dead ones | Accepted | architecture/constants, daer-common, daer-control | Delete constants no code reads; device names live only in the crate that creates the devices; a test asserts every exported constant has a reader. | 2026-11-06 |
| [0024](0024-datapath-source-layout.md) | The datapath source is split by map ownership and attach domain | Accepted | ebpf/kernel-c, datapath | Split `tproxy.c` into modules whose cut lines are map ownership and attach domain; `datapath.c` is a 60-line include list with no logic; one translation unit keeps whole-program optimisation so the 512-byte stack margin survives [[INV-DATAPATH-ABI-01]](../dev/standards/invariants.md). | 2026-11-06 |
| [0025](0025-verification-at-the-privilege-boundary.md) | Verification is split at the privilege boundary, and `--dry-run` means "change nothing" | Accepted (Amended by ADR-0038) | verification, cli/surface, datapath, packaging | Two gates: `daer check [--object]` and `daer run --dry-run` need no capability and mutate nothing; only `daer run` binds, creates, writes and attaches. The privileged gate now includes the private ingress namespace and `CAP_SYS_ADMIN`. `--dry-run` returns before the first mutating call, by construction [[INV-PREFLIGHT-01]](../dev/standards/invariants.md). | 2026-11-06 |
| [0027](0027-one-intermediate-rule-set.md) | One intermediate rule set: readers convert to it, one writer encodes it | Accepted | routing/drb, architecture/boundary, daer-rule-ast, daer-drb | Every source format reads into `daer_rule_ast::RuleSet`; `DrbSet::from_rule_set` is the only writer; normalisation (fold, validate, sort, dedupe) lives once in the AST; source attributes are preserved and filterable; `decompile` makes a release auditable. Deletes `from_prefixes`/`from_patterns`. | 2026-11-06 |
| [0031](0031-drb-v2-and-canonical-rules.md) | DRB v2 Binary ABI and Canonical Rule Source (CRS) | Accepted | routing/drb, ebpf/lpm, rule-ast, daer-drb | Clean break: delete `daer-geodata` and legacy Protobuf; DRB v2 stores only disjoint closed intervals for IP (zero-copy mmap binary search, on-demand decomposition to eBPF LPM) and Compact Reverse Label Radix for domains (zero heap allocation, elimination of negative lookup fallacy); deterministic byte-for-byte builds. Supersedes ADR-0014, ADR-0019, ADR-0027. | 2026-11-06 |
| [ADR-0028](0028-protocol-layering.md) | A proxy protocol is a stack of orthogonal layers, and each layer is a type | Accepted | outbound/protocols, vless, vmess, vision, reality, transport/ws, config/nodes | The transport/security/protocol/flow layers are separate types composed in one place per protocol; REALITY is a security layer, Vision belongs to VLESS, and an unimplemented layer is a load-time error that names it. | 2026-11-06 |
| [ADR-0029](0029-hysteria2-socket-stack.md) | Hysteria 2 is carried by a socket stack, and daer implements all of it | Accepted | outbound/protocols, hysteria2, transport/udp, quic, config/nodes | The QUIC endpoint consumes a `QuicUdpSocket` stack (obfs, hop) through a per-connection `QuicUdpSocketFactory`, so a socket wrapper cannot be forgotten; obfs, fragmentation, per-flow session ids, the server's CC answer and source-port hopping are all implemented. | 2026-11-06 |
| [ADR-0030](0030-vmess-aead-only.md) | VMess is VMess AEAD only; the legacy handshake is not implemented | Accepted | outbound/protocols, vmess, crypto, config/nodes | Only the AEAD format, whose KDF is a nested HMAC by aliasing hashers; the legacy replayable handshake is not expressible, and a non-zero alterId is a load error. | 2026-11-06 |
| [0032](0032-flat-front-coded-domain-table.md) | The domain table is flat and front-coded, not a trie | Accepted | routing/drb, routing/lookup, architecture/boundary | Measured: reverse-label radix gave 1.002 nodes/rule (no sharing) and +61% artifact size, and was 7x slower on miss-heavy input. Replace with a reversed-label-sorted, front-coded flat table: every published artifact is now smaller than DRB v1 (geosite-cn −37%). Supersedes the domain half of ADR-0031. | 2026-11-06 |
| [0033](0033-one-domain-table-two-vocabularies.md) | One domain table, two vocabularies, no engines | Accepted | routing/lookup, routing/drb, dns/fake-ip, architecture/boundary | Delete `DomainIndex`/`DomainKey`: one `DomainTable` serves the artifact, the evaluator and inline rules, removing the 38 ms per-generation bridge. Routing accepts only hierarchical domain patterns (a bare name is a suffix in both config and `.rules`); spellings later became symbolic in ADR-0036. `keyword:`/`regex:` move to `daer-dns`, which owns its own exclusion language. `aho-corasick` leaves `daer-routing`. | 2026-11-06 |
| [0034](0034-shadowsocks-2022-and-aead-dual-stack.md) | Shadowsocks 2022 and AEAD dual-stack protocol architecture | Accepted | outbound/protocols, protocol/shadowsocks, crypto, config/nodes | Implement Shadowsocks 2022 (SIP022) alongside classic AEAD with strict physical modularity (`v1/` vs `v2/`); modern BLAKE3 KDF, randomized 1..=900 padding, ±30s timestamp window, echoed salt verification, and AES-ECB obfuscated UDP session/packet tracking. Legacy stream ciphers remain banned. | 2026-11-06 |
| [0035](0035-quic-and-http3-in-netune.md) | QUIC and HTTP/3 client transports migrate to netune; daer drops quinn and ring | Accepted | outbound/protocols, hysteria2, quic, http3, architecture/boundary, crypto | netune 0.0.24 owns QUIC and HTTP/3; daer deletes direct `quinn`, `h3`, `h3-quinn` and `ring` dependencies and consumes `netune-quic`/`netune-http3`, keeping only product semantics through `QuicUdpSocket`, `CongestionControllerFactory`, keep-alive and peer-certificate seams. | 2026-11-07 |
| [0036](0036-canonical-rule-source-v2-and-symbolic-syntax.md) | Canonical Rule Source (CRS v2) symbolic syntax and topology discipline | Accepted | routing/drb, rule-ast, daer-drb, config/rules, docs | Retire legacy `full:` keyword in favor of `=domain`; bare domain is suffix, `.domain` is subdomains-only; reject `^` and arbitrary wildcards; mandate disjoint rule topology separating IP and Domain to preserve eBPF kernel offload [[INV-RULE-TOPOLOGY-01]](../dev/standards/invariants.md). | 2026-11-07 |
| [0037](0037-per-provider-refresh-cadence.md) | Per-provider refresh cadence, content-gated generation swaps | Accepted | control-plane/rule-provider, cli/run, routing/generation, observability | HTTP providers refresh on their own declared interval; the supervisor wakes on the shortest one and `due()` decides which are served. A content-identical refresh does not rebuild the routing generation, discard measured latency or restart health probes; a failed refresh keeps the running rules. | 2026-11-07 |
| [0038](0038-private-ingress-network-namespace.md) | The transparent ingress lives in a private network namespace | Accepted (Amends ADR-0013, ADR-0025) | architecture/boundary, datapath, transparent-ingress, packaging, cli/run | Move `daer0peer`, the transparent listeners, and local-delivery routing into `daer0ns`; the host keeps `daer0`, forwarding, and the redirect source. The table rule is keyed by `iif daer0peer`, not fwmark, so marked listener replies leave through the peer instead of looping to `lo` [[INV-DATAPATH-01]](../dev/standards/invariants.md). | 2026-11-11 |
| [0039](0039-remove-rule-attributes.md) | Remove rule attributes from Canonical Rule Source | Accepted | routing/drb, rule-ast, daer-drb, drb-sets, docs | Delete `@attribute` suffixes, `DomainRule::attributes`, attribute filtering (`--without`) and the `without` config key. The DRB binary is unchanged; CRS carries patterns only. | 2026-11-11 |
| [0040](0040-typed-diagnostic-plane.md) | Observability is a typed diagnostic plane: events, correlation IDs, and incident bundles | Accepted (Amends ADR-0007, ADR-0021) | architecture/observability, diagnostics, datapath, cli/surface, verification | Add `daer-observe` as the Layer 1 event/correlation/incident foundation; generate the event catalog from one declaration; make client-visible failures typed `warn` events; consume `bpf_stats_map` and `event_ringbuf` through the single-source ABI; enforce incident records and redaction in CI [[INV-EVENT-01]](../dev/standards/invariants.md), [[INV-FLOW-01]](../dev/standards/invariants.md), [[INV-FORENSIC-01]](../dev/standards/invariants.md). | 2026-11-11 |
| [0041](0041-runtime-status-verb.md) | The CLI gains a read-only runtime inspector: `daer status` | Accepted | cli/surface, architecture/diagnostics, observability | Add `status` as a seventh, read-only verb; the daemon owns a versioned snapshot served over `/run/daer/control.sock` with `/run/daer/state.json` as the crash fallback; no HTTP endpoint, no producer, no second service. Amends ADR-0015/ADR-0016 and [[INV-CLI-01]](../dev/standards/invariants.md). | 2026-11-11 |
