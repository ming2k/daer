# Architectural Decision Records

This directory records high-impact, non-reversible architectural and structural decisions made across the `daer` project.

| ID | Title | Status | Scope | Decision Summary & Primary Invariant | Date |
| :--- | :--- | :--- | :--- | :--- | :--- |
| [0001](0001-config-format.md) | The configuration format is TOML | Accepted | config/schema, config/parser | Abandon custom ANTLR DSL; adopt strictly-typed TOML with `deny_unknown_fields` and compile-time schema generation. | 2026-01-07 |
| [0002](0002-netune-boundary.md) | Network capabilities live in netune; the data path lives here | Accepted (Amended by ADR-0010) | architecture/boundary, outbound/transport | Keep generic network capabilities in `netune`; proxy appliance data path, eBPF maps, transparent accept, and proxy protocols stay in `daer` [[INV-NETUNE-01]](../dev/standards/invariants.md). | 2026-01-07 |
| [0003](0003-datapath-abi.md) | The datapath object is an external artifact with its own ABI | Accepted | ebpf/abi, kernel/c, datapath | Treat C eBPF datapath as an external artifact compiled via clang; access maps and programs via stable Aya ABI without linking C. | 2026-01-07 |
| [0004](0004-routing-epochs.md) | Routing epochs: two slots, publish then switch | Accepted | ebpf/maps, routing/hot-reload, kernel/sync | Dual-slot kernel routing epochs (`active_slot` toggle); fully publish new generation before switching [[INV-EPOCH-01]](../dev/standards/invariants.md). | 2026-01-07 |
| [0005](0005-kernel-policy-encoding.md) | The kernel policy table is written, and it is either provably equivalent to userspace or it defers | Accepted | datapath/policy, routing/lowering, control-plane | Lowers routing rules to kernel eBPF tables when provably equivalent; explicitly defers to userspace with logged reasons when predicates require userspace tables [[INV-KERNEL-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0006](0006-wiring-ownership.md) | A running daemon owns its whole data path: adapters that are not wired are deleted, not documented | Accepted | control-plane, outbound/selection, config, cli | Unify configuration loader across CLI diagnostics and running daemon (SSOT); delete unwired keys and enforce with automated script [[INV-LOADER-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0007](0007-verification.md) | A test that cannot fail is a liability: every claim about the data path names its falsifier | Accepted | verification, ci, documentation | Every datapath claim must name its falsifier and carry negative controls; reject tests that cannot fail [[INV-VERIFY-01]](../dev/standards/invariants.md). | 2026-10-30 |
| [0010](0010-reality-client-ownership.md) | REALITY and the minimal TLS 1.3 client belong to daer-outbound | Accepted | tls/reality, protocol/vless, security/egress | Implement unauthenticated TLS 1.3 client and REALITY directly in `daer-outbound` because netune cannot perform dials without CA validation. | 2026-10-29 |
| [0011](0011-partitioned-kernel-routing.md) | Partitioned kernel routing and DNS snooping for Real-IP datapaths | Accepted | datapath/policy, routing/lowering, control-plane, dns | Compile deterministic L4/IP prefix rules directly to kernel eBPF; gate unencodable rules at the partition boundary and accelerate Real-IP via DNS snooping [[INV-PARTITION-01]](../dev/standards/invariants.md). | 2026-01-08 |
| [0012](0012-optional-fake-ip-ebpf.md) | Pluggable Fake-IP subsystem and eBPF domain-bitmap synthesis | Accepted | dns/fake-ip, datapath/ebpf, control-plane/routing, config/schema | Isolate Fake-IP behind an optional disabled-by-default table; synthesize eBPF `domain_routing_map` entries for line-rate kernel domain routing [[INV-FAKEIP-01]](../dev/standards/invariants.md). | 2026-01-08 |
